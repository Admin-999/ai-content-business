1. Оператор данных

Оператором персональных данных является [НАЗВАНИЕ КОМПАНИИ / ИП ФИО], контакт для запросов о данных: [PRIVACY@EMAIL.RU].

2. Какие данные мы собираем

  • email адрес и хеш пароля (пароль хранится только в виде необратимого хеша bcrypt);
  • темы запросов и сгенерированные тексты (история генераций);
  • служебные данные: дата регистрации, тариф, счётчики использования, технические логи.

3. Зачем мы обрабатываем данные

  • предоставление доступа к Сервису и авторизация;
  • учёт лимитов генераций и ведение истории;
  • отправка сервисных писем и отчётов (если вы зарегистрированы);
  • обеспечение безопасности и предотвращение злоупотреблений.

4. Передача данных третьим лицам

Для работы Сервиса мы используем сторонних провайдеров, которые обрабатывают данные в объёме, необходимом для их функций:

  • Groq — текст вашего запроса (тема) передаётся этому ИИ-провайдеру для генерации текста;
  • Modal — хранение базы данных и работа API (аккаунты, генерации, подписки);
  • GitHub Pages — хранение файлов сайта.

Мы не продаём персональные данные третьим лицам.

5. Файлы cookie и локальное хранилище

Мы не используем трекинговые cookie. Для поддержания сессии в браузере хранится токен авторизации (localStorage). Аналитические системы по умолчанию не подключены.

6. Безопасность

Мы применяем отраслевые меры защиты: хеширование паролей (bcrypt), JWT-токены с ограниченным сроком действия, шифрование трафика (HTTPS), изоляцию секретов в переменных окружения. Абсолютная безопасность передачи данных через интернет не может быть гарантирована.

7. Срок хранения и удаление данных

Данные хранятся, пока аккаунт активен. Вы можете запросить доступ к своим данным, их исправление или удаление (включая удаление аккаунта) письмом на [PRIVACY@EMAIL.RU] — запрос обрабатывается в течение 30 дней.

8. Несовершеннолетние

Сервис не предназначен для лиц младше 18 лет, и мы не собираем их персональные данные намеренно.

9. Изменения политики

Актуальная редакция всегда доступна на этой странице. Существенные изменения дополнительно доводятся до пользователей по email.
